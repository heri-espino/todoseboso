La regla corregida presenta RMSE 0.462418 y R² 0.702693 sobre las 138 etiquetas observadas. En el selector anidado, esa variante fue elegida en 128 de 138 exclusiones; 5 escogieron PCA8 y 5 mantuvieron la referencia sin corrección.

Cómo se construye una predicción

No es un clasificador de parcelas ni un nuevo modelo entrenado con datos sintéticos. Conserva el predictor Reference26 y añade una corrección acotada con observaciones reales, seleccionada mediante validación cruzada.

01

Predicción de partida

Reference26 combina señales climáticas, satelitales, espaciales y geológicas. En este estudio utiliza imputación por media calculada en entrenamiento para obtener una predicción inicial del rendimiento.

02

Tres parcelas análogas

La corrección más seleccionada busca las 3 parcelas más próximas en el espacio de las 26 variables escaladas robustamente, y calcula una media de sus cosechas observadas ponderada por distancia. Las parcelas reservadas nunca aportan su rendimiento.

03

Corrección controlada

La mezcla utiliza un peso de 0.25, atenuado cuando falta cercanía o hay desacuerdo entre vecinos. El cambio queda limitado a ±0.5 t/ha. Una selección interna puede escoger otra corrección o no aplicar ninguna.

La elección también se valida

En cada una de las 138 exclusiones externas, se aparta una parcela real. Sólo con las otras 137 cosechas se hacen cuatro particiones internas: allí se evalúan cinco formas de corrección y la posibilidad de mantener la predicción base.

Se realizan 552 ajustes internos de Reference26 a lo largo de los 138 folds externos. Se elige la opción con menor MSE interno, siempre que una corrección mejore el MSE original al menos 1 %. La receta elegida predice después la parcela externa sin utilizar su rendimiento. Así se construyen las 138 predicciones utilizadas para calcular las métricas superiores.

Detalle de las métricas y del alcance

Fórmula del promedio local y del factor de confianza

Para las tres parcelas elegidas, la media análoga pondera cada rendimiento observado con el inverso de su distancia: wⱼ ∝ 1/max(dⱼ, 10⁻⁵), normalizando los tres pesos para que sumen uno. Las distancias se calculan sobre las 26 variables escaladas robustamente. El factor de confianza es g(x) = exp[−½(dₘᵢₙ/s)²] / [1 + (σᵥₑc/σₑₙₜ)²], donde s es la distancia mediana al vecino más próximo entre parcelas de entrenamiento, σᵥₑc es la dispersión ponderada de rendimientos de los vecinos y σₑₙₜ es la desviación estándar del rendimiento de entrenamiento. Así una consulta poco representada o con vecinos discordantes recibe una corrección menor.

Definiciones estadísticas de las cuatro métricas

Con residuos firmados eᵢ = predicciónᵢ − cosechaᵢ y 138 predicciones excluidas, RMSE = raíz del promedio de eᵢ²; MAE = promedio de |eᵢ|; sesgo = promedio de eᵢ; R² = 1 − suma(eᵢ²) / suma[(cosechaᵢ − media observada)²]. RMSE, MAE y sesgo se expresan en toneladas por hectárea; R² no tiene unidades. No se informa R² ajustado para este predictor compuesto. No se publica un intervalo del RMSE absoluto porque todavía no se cuenta con sus límites verificados.

Qué cambia en el entrenamiento final de las 59 parcelas

Para una entrega, Reference26 se entrena con las 138 cosechas reales y la elección de corrección se vuelve a hacer mediante cuatro folds internos sobre esas 138. Después se aplica la regla seleccionada a las 59 parcelas sin rendimiento conocido. Este apartado comunica resultados LOOCV; no confirma todavía que las estimaciones corregidas para las 59 se hayan publicado en esta web. Las 59 parcelas con rendimiento desconocido todavía no tienen métricas de error.

Limitaciones de la validación anidada

La selección interna de cada fold no utiliza el rendimiento de su parcela externa. Sin embargo, las cinco reglas candidatas se eligieron después de estudiar repetidamente los mismos 138 rendimientos. Por eso la validación es anidada de manera condicional, no una evaluación independiente de todo el proceso de investigación. El RMSE de 0.462892 t/ha no es el error observado de las 59 parcelas desconocidas.
